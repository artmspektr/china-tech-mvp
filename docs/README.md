## 🔧 УСТАНОВКА И НАСТРОЙКА

### ТРЕБОВАНИЯ:
- Node.js 18+
- Git
- Аккаунт Vercel (бесплатно)
- Telegram Bot Token
- Google Gemini API ключ

### БЫСТРАЯ УСТАНОВКА:
```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/china-tech-mvp.git
cd china-tech-mvp

# 2. Установить зависимости
npm install

# 3. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env файл

# 4. Локальный запуск
npm run dev
```

## 🚨 УСТРАНЕНИЕ ПРОБЛЕМ

### ЧАСТЫЕ ОШИБКИ:

**Парсеры не работают:**
- Проверить User-Agent
- Возможно нужен прокси

**Gemini API лимиты:**
- Добавить больше ключей для ротации
- Увеличить задержки между запросами

**Telegram не публикует:**
- Проверить права бота
- Убедиться что бот добавлен в канал

### ЛОГИ И ОТЛАДКА:
```bash
# Просмотр логов в Vercel
vercel logs
```
