# Проектная документация по мировым стандартам

## 1. Введение

Данный документ описывает проектную документацию, разработанную в соответствии с международными стандартами проектирования программного обеспечения, включая аспекты безопасности и использования искусственного интеллекта.

## 2. Стандарты проектирования

### 2.1. ISO/IEC 12207:2017 - Software life cycle processes
Этот стандарт определяет процессы жизненного цикла программного обеспечения, которые должны быть соблюдены в нашем проекте.

### 2.2. ISO/IEC 27001:2013 - Information Security Management
Стандарт по управлению информационной безопасностью, который будет применяться для обеспечения безопасности нашего приложения.

### 2.3. IEEE 830-1998 - Recommended Practice for Software Requirements Specifications
Рекомендации по написанию спецификаций программных требований.

### 2.4. ISO/IEC 23053:2022 - Framework for AI system support in software and systems engineering
Новый стандарт, касающийся интеграции систем искусственного интеллекта в программную инженерию.
