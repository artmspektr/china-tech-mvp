## 🛠️ ТЕХНОЛОГИЧЕСКИЙ СТЕК:

- **Database:** PostgreSQL, Redis, MongoDB (при необходимости)
- **Infrastructure:** Docker, Kubernetes, AWS/Azure/GCP
- **DevOps:** CI/CD pipelines, monitoring and logging solutions
